System Architecture / 02 — The Memory Loop

EVERY DRIFT MAKES THE NEXT ONE SHARPER.

ClaimDrift doesn’t score each case from scratch. Detections are distilled into reusable patterns in Elastic; the next analysis retrieves them with ELSER semantic search and calibrates its severity against accumulated base rates. A blind A/B test moved a materiality score from 0.50 to 0.82 once priors accrued.

Why no threshold
RRF-blended scores are rank-based, not relevance-measuring. The agent reads each pattern and decides — the way a human reviewer would.
Why append-only
The live write path never rewrites descriptions — only adds evidence. Refinement is deferred to the offline Curator, so retrieval stays stable.
Dual ELSER endpoints
.elser-2-elastic serves live reads; claimdrift-elser-batch handles Curator re-embedding — governance never throttles production retrieval.
